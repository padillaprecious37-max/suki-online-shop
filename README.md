# Suki Online Shop

Starter marketplace website for Suki Online Shop.

## Local setup

1. Copy `.env.example` to `.env`
2. Put the Supabase Project URL in `VITE_SUPABASE_URL`
3. Put the Supabase Publishable Key in `VITE_SUPABASE_PUBLISHABLE_KEY`
4. Run `npm install`
5. Run `npm run dev`

Never put a Supabase secret/service_role key in this project.
